# Abdul-Azeez Olanrewaju — Portfolio

A static, responsive portfolio website for GitHub Pages.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `thecrescentvoice.github.io` (if that username is available and is your GitHub account's exact username).
2. Extract this ZIP and upload `index.html` and `styles.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The usual URL is `https://thecrescentvoice.github.io/` only if `thecrescentvoice` is your exact GitHub username.

Before publishing:
- Confirm all project descriptions are accurate and public-safe.
- Add links to live demos or repositories only where you have permission and the links work.
- The site does not claim unverified Figma, automated testing, or formal degree credentials.
